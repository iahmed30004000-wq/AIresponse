## 3. طريقة شغل البنّاء (كل جلسة)

1. `git fetch origin && git checkout main && git pull` ثم فرع جديد `restructure/<رقم>-<اسم>` من `main`.
2. اقرأ: هذا الملف ← الحزمة بـ `06-WORK-PACKAGES.md` ← الأقسام اللي بتشير إلها **بس**.
3. اكتب «تعريف الإنجاز» بأول وصف الـ PR (القالب بآخر `06`).
4. **الاختبار أول:** اكتبه، شوفه بيفشل، صلّح، شوفه بينجح.
5. البوابات الخمس: `npm run typecheck` · `npm run lint` · `npm test` · `npm run scan:secrets` · `npm run build`.
6. PR على `main` — **ممنوع الرفع المباشر**. الحكم للـ CI، مش «أخضر عندي».
7. آخر الـ PR: 5 أسطر للمالك بالعربي (شو تغيّر · كيف يجرّب · ⚠️ الخطر · 🔧 التصحيح) وسطر بـ `docs/PROGRESS.md`.
8. اللي بتلاحظه برّا نطاق الحزمة ← سطر بـ `docs/restructure/BACKLOG.md`. **ما بينصلح بنفس الـ PR.**

## 4. قواعد ما بتنكسر

من `AGENTS.md` (المرجع الأعلى — اقرأه كامل) + دروس هالخطة:

1. **حزمة وحدة مفتوحة بكل لحظة.** وكيلين على نفس الريبو = شغل ضايع.
2. **ترحيل إضافي بس.** لا حذف عمود ولا تغيير نوع. أي أداة بتعرض «reset» للقاعدة: الجواب لا، وقّف وبلّغ.
3. **ولا بيانات عميل (اسم · رقم · عنوان) لموديل خارجي.** كل نداء ذكاء فيه نص عميل بيمر من `ai/privacy-gate.ts` وعلى مزوّد المساحة. ولا قيمة حساسة بالسجلات.
4. **السعر من قاعدة البيانات دايمًا.** الموديل ما بيحدد سعر ولا مجموع ولا رسم.
5. **ما تعيد بناء الموجود.** قبل أي دالة جديدة: `grep`. القائمة §6 تحت.
6. **ما منلغي ميزة — منعلّمها.** أي شي مؤتمت أو خطِر: `Callout` أحمر وتحته التصحيح البرتقالي. الحذف المسموح هو المكتوب صراحة بالخطة (`02` §15 · `03` §8) وبس.
7. **ولا اختبار بينحذف بلا بديل** بنفس الـ PR. الاختبارات القديمة بتضل خضرا.
8. **مفاتيح الانتقال:** `orderMode` (المسودة ↔ القارئ) و`uiVersion` (الواجهة القديمة ↔ الجديدة). الجديد بيندمج بـ `main` مطفي، وبيتفعّل بقرار المالك، وبيرجع بكبسة.
9. **`contracts/` ما بينلمس.** وأي تغيير بيلمس الـ OMS: وقّف واسأل.
10. ثوابت الواجهة: `PasswordInput` لكل سر · ولا «Hermes» بنص ظاهر · ألوان من المتغيّرات بس · صفحة جديدة = `NAV_GROUPS` + `PAGE_KEYWORDS` + `PAGE_GUIDES` · مفتاح عدم تكرار جديد فيه المساحة.
11. **الرد على المالك بالعربي الأردني، نتيجة مباشرة بلا خطوات داخلية.**

## 5. وقّف واسأل المالك — ما تخمّن

- قرار من §7 ما إله جواب والحزمة بتعتمد عليه.
- المواصفة والكود متعارضين بشي بيغيّر سلوك ظاهر للعميل أو للمالك.
- لازم تحذف شي مش مكتوب إنه بينحذف.
- حساب مبالغ أو إنشاء طلب لازم يتغير بطريقة مش موصوفة.
- ترحيل ما بيزبط إضافي.
- اختبار قديم ما بيخضرّ إلا بتغيير معناه.
- أي تفعيل على الإنتاج (`orderMode` · `uiVersion` · مفاتيح الحزمة 0.1) — **المالك هو اللي بيكبس.**
